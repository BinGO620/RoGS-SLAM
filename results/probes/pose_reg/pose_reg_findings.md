## 关键发现（C2W 修正口径）

### 1. 平移路径过走 1.28×（不是初版 1.10×）+ 旋转与 GT **符号相反**（非欠转）
- **平移路径比 est/gt = 1.276**（初版因用错中心测成 1.10，低估 ~2.5×）；raw 相机中心距离
  mean **133cm / max 244cm**。
- **旋转不是"欠转"，是"转向相反"（9/9 全同）**：yaw 采样 f0→f579，est 从 +0.7° 单调冲到 +169°
  再回 +/-（顺时针 ~+173°），GT 从 +0.7° 反向到 -146°（逆时针 ~-161°）；在 |gt_yaw_rate|>0.3° 的
  帧上 est 与 GT **符号一致率仅 ~0.11**（88.6% 相反），corr(est_rate,gt_rate)= **-0.63**。
  ⇒ 这是**方向性符号偏置**（est 转反了），不是幅值不足。初版"0.35× 欠转"是测地线绝对值求和的假象
  （把正反向都记正数再比大小）。

### 2. 报告口径的解耦：9.16cm 是**纯平移增量误差**，旋转对报告 ATE 是"免费的"
- **决定性替换**（C2W，evo SE(3) 对齐后）：
  - `gtROT + estTRANS`（把 est 旋转换成 GT 旋转，保 est 平移）→ ATE **9.16cm 不变**；
  - `estROT + gtTRANS`（保 est 旋转，平移换成 GT）→ ATE **0.0cm**。
- ⇒ **报告的 person-ATE 9.16cm 完全由逐帧平移增量 T 的误差决定**；旋转漂移（无论欠转还是转反）
  都被 evo 4DOF SE(3) 对齐**全吸收**，对报告 ATE 贡献 0。**初版"方向 ≈100%"与 hermes"转反"都是讲
  RAW path，都不改变报告度量。**
- 平移增量残差是**低-中频慢漂移**：逐帧 err 自相关 lag1=**0.99**（高度平滑），在 ~150 帧尺度爬升
  （f1 6.7→f100 10.6→f300 2.7→f500 10.5cm）⇒ 非随机游走，是系统性平移漂移。

### 3. 长度/方向拆分（C2W，近等）→ 步长正则救不了
- `GTlen+estdir`（纯方向）ATE = **11.7cm**；`estlen+GTdir`（纯长度）= **12.0cm**——**两通道近等**，
  初版"长度≈0%"是错的（用的错误中心构造了错误死推）。但**两者都 ≈ 9.16 量级、毫无增益**：
  死推用 GT 步长替换只从 ~132 原始漂移到 ~52cm（对齐后 9-12），都不收敛到 9.16 的"能修"空间。

### 4. 特征锚反例（构造成缺陷，但结论方向仍否）
- 初版"完美 GT 全姿态锚 K=60 反而 42.9cm"用**est 增量回放**构造，是 strawman。
- hermes 对照（**GT 锚间插值模拟 re-solve**）：K=15→1.08 / K=30→2.76 / **K=60→7.67cm**，K=60 优于
  9.16 baseline ⇒ **若真有独立观测在锚间产生合理增量，特征锚有正向价值**。← 这条**推翻**初版否掉候选③。

## 裁决（如何读）
- **轨迹形状 / 恒定速度先验（候选①）**：报告口径下 9.16cm 是**逐帧平移增量漂移**（低-中频，
  autocorr 0.99）。但死推证明**步长(length)通道不是主项**（`estlen+GTdir` ATE 12.0 ≈ `GTlen+estdir` 11.7，
  替换步长不收敛到 9.16）；残余是**方向性 T 增量**（across-motion > along）。对"方向性平移漂移"
  的平滑先验，等价于局部 photometric T 增量 tweak——**codex 已判此维饱和**（RPE 1.60 优于 RGD，
  靠局部加权关 ATE 差距非良定义目标，见 `pt2_edge_generalization_codex_round2.md` §4）。**候选①低优先。**
- **航位推算死区一致（候选②）**：主要约束平移连段一致，但航位推算由同一跟踪增量继承同一个
  平移增量偏置，**非独立观测**（与①同根，无新信息）。**候选②不值跑。**
- **特征锚（候选③）**：初版 strawman 反例已撤回；hermes 插值对照（K=60→7.67cm）证明**若真有独立
  观测能在锚间产生合理增量，特征锚有正向价值**。**但**仓库现成信号（GTMC mask 非特征、无分割网络
  独立特征、拒绝 ORB 现成 `full_frame_pose.py` 的使用）**没有能产生"更优观测增量"的特征锚来源**。
  ⇒ 候选③**方向 open 但实现源缺失**：只在"能否造出独立位姿观测"这个新前提上有意义。
- **旋转通道正则**：9/9 转反（corr -0.63）是 RAW path 现象，但**报告 ATE 对齐后旋转贡献 = 0**
  （`gtROT+estTRANS`=9.16 不变），且 yaw 翻转 oracle 不改变 ATE ⇒ **旋转正则对报告 metric 无收益**。

## 方法面结论（诚实）
- **报告 metric 视角（决定性）**：pt1 9.16cm 是**逐帧平移增量漂移**，旋转被对齐吸收贡献 0。
  候选①②③里：①本地域已饱和、②非独立、③缺独立观测源。**没有一个能用现成信号把 person-ATE
  关上（朝 RGD 7.2）**；唯一有正向上界的是③特征锚，但它需要"造出独立位姿观测"，已是换估计器范畴。
- **raw path 视角（诚实补充）**：est 旋转与 GT 符号相反（9/9），这是显著的可解释偏差，但跟报告
  ATE 解耦。写作上可作为机制观察记录（"dense-edge 光度跟踪在 person 快速转向时反向旋转"），
  不作为 ATE 主张。
- ⇒ **不烧进一步 GPU 追 person-ATE**；算力还给双层头条主线（mask-free 内核消融 / 18-seq 主表
  缺口 / combined 渲染-几何指标）。pt1 9.16 记为**当前 dense-edge 光度跟踪公式在 person 序列的
  empirical limit**（codex 已定，非数据集 floor），写作为适用域边界 + RPE 优于 RGD。
