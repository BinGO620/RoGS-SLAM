## 2. 判：假设**不成立**

exp35 §2 写下的可检验解释是「全帧 PSNR 奖励把动态人烤进地图」，预言**排除动态像素后
次序应消失或翻转**。实测：

```
maskfree − eboth:   全帧 +2.27 dB   →   静态带 +1.76 dB   （3/3 seed 仍然更高）
```

排除 GT 动态像素只拿掉了 **22%** 的差距，次序**原封不动**。
⇒ **那个解释最多解释五分之一，不能作为「PSNR 有偏」的机制。**（exp35 把它标成
"可检验的解释（假设）"是对的；本轮把它检验掉了。）

## 3. 那么是什么

三条同时成立的观测：

1. **不是「动态像素」的问题，是「光度族指标」的问题**：在**同一套静态支持集**上，
   PSNR 偏爱 mask-free（3/3），而 SSIM（0.7937 vs 0.7589）与 DepthL1（8.79 vs 10.50）
   偏爱 mask。⇒ exp35 的**结论**（评 mask 方法别用全帧 PSNR，用 SSIM/LPIPS 或几何量）
   仍然站得住，**理由要换**。
2. **ATE 更差的臂，光度拟合更好**（maskfree ATE 11.36 / PSNR 20.39 vs eboth 3.06 / 18.62）
   ⇒ 这个指标很大程度在量「**每个地图对自己那套（各自漂过的）训练视角的解释程度**」，
   不是重建精度。跨臂比较位姿不同 ⇒ 绝对 PSNR 不可当精度读。
   **唯一与 ATE 同序的列是 DepthL1**（对 GT 深度，几何参照）：mask 臂在整带（8.79/8.89）
   与 vacated 区（10.04/10.12）都赢。
3. **mask 的代价确实**在 mover 待过的地方**相对更大**：ghost（同帧内对比）eboth −4.41
   最深、maskfree −3.07 最浅，差 1.34 dB。但**不能**读成「mask 留洞」——因为 maskfree 的
   nonvacated 背景（22.89）也高于 eboth（22.54），它在两个区都更"好"，只是在 vacated 区
   领先得更多。诚实说法：**相对代价在 vacated 区更大，绝对代价两个区都有，且与位姿差混在一起。**

## 4. 副产物：渲染侧按 `mask_mapping` 分成两组，第三条独立观测量

静态带 PSNR：**map ON = 18.62 / 18.40；map OFF = 20.39 / 20.39 / 20.39**
（三个 map-OFF 臂两位小数完全相同）。⇒ **地图是由 `mask_mapping` 这一条通道决定的**，
insertion 与 tracking 侧都不动它。这与 ATE 侧 exp34/35 的判决在**第三个独立观测量**上一致。

**对 balloon 那条 INDETERMINATE 的旗标（⚠ 描述性，不能翻判决）**：E 与 D 的地图在渲染侧
**无法区分**（静态带 PSNR 完全相同、ghost/fresh 同量级）。所以如果 balloon 上 E 比 D 好的
2.3 cm 是真的，它**不可能是地图质量效应**，只能来自位姿侧 —— 而位姿侧正是 tracking 通道
所在。这与 §判决里「要分开必须换 estimand（逐帧/配对位姿口径）」指向同一处。
**这是下一个预注册问题的线索，不是本轮判决的补丁。**

## 5. 适用域与缺口（写下来）

- **只有 balloon 与 pt1 有冻结 GTMC mask**（440 / 582 张）；**f3_wk_xyz 是 0 张**
  ⇒ 静态带口径在那条判别序列上**不可得**。本轮的静态带结论只在 balloon 上成立。
- **忠实性锚缺失**：这些 run 是 `--fast` 跑的，盘上没有 `band_metrics.json`
  ⇒ `eval_vacated_posthoc` 的 band 对齐检查被跳过（`band_check: "no-stored-band"`）。
  五臂走同一条 posthoc 路径 ⇒ 跨臂比较是同一把尺；但「与在线 eval 逐 dB 对齐」这批**没有**
  （exp35 那批 39 run 全帧读数也同样没有，之前没写明）。
- **可分解性门仍然不过**：exp35 在全帧上 12/12 不可分解，本轮没有重新赢得它
  ⇒ 全部读数**只读方向（k/3）不读比值**。
- **同 run 配对已修**：exp35 的 balloon eboth 的 ATE 取自 T2 根、全帧渲染取自 PBA 根
  （同 config 的两次不同物理 run，复跑差 3.9%）。本轮把 PBA 根 eboth 也补了静态带，
  表里五臂的全帧与静态带都来自**同一次物理 run**。
