# exp42 Phase −1 —— 渲染误差三带分解 + 动态重建可达域（零 GPU campaign，2026-08-23）

> **结论先行：我自己提的「动态渲染分支」方向，头条被我自己的探针判死。**
> 完美重建动态内容的全帧增益上界 = **+1.43 dB（balloon）/ +0.33 dB（mv_no_box）**，
> 而 balloon vs RGD-SLAM 的渲染差距是 **3.58 dB**。按跑前写进脚本 docstring 的判读规则
> （<1.0 判死 / 1.0–3.58 降级为「差距的一部分」/ ≥3.58 成立），**该方向不支持头条**。

装置 `scripts/exp42_band_decomposition.py`（复用项目自己的离线渲染路径，同一把尺）。
读数 `exp42_band_decomposition_{balloon,mvnobox}_combined_seed0.json`。

## 0. 为什么做这个测量

73 个注册实验的火力全部打在 ATE 侧；渲染侧只有全帧/静态带两个聚合数（exp35/36），
**从没人问过「渲染误差到底分布在哪条带上」**。而候选方向的头条理由正是
"重建被 mask 删掉的动态内容 ⇒ 关闭 3.58 dB 渲染差距"，属于判据 #11
（先算可达域，再决定跑不跑）必须先拦一道的那类主张。

## 1. 我在这轮里犯的错（完整保留，因为它是判据 #16 的又一个实例）

**第一次尝试用解析反解**：由 exp36 的全帧 17.31 dB 与静态带 18.78 dB，
配上本轮实测的动态像素占比 6.2%，反解出"动态带 = 10.04 dB"，并进一步推出
"RGD 的动态带必须 ≥13.1 dB ⇒ 它在重建动态内容"。

**两条都撤回。** 静态带支持集是 `(GT 深度有效) AND NOT(GTMC 动态)`，
而 balloon 上**深度无效像素占 14.0%**（本轮实测）——它们在全帧支持集里、不在静态带里，
于是"全帧 − 静态带"的超额误差被整包错记到 6.2% 的动态像素头上。

**直接测量给出的真值：动态带 20.96 dB，与我的反解差 11 dB。**
⇒ 判据 #16（分母要逐通道审计）在渲染侧的第一个实例；
"两个聚合数相减得到第三个带"在支持集不互斥时是错的。

## 2. 三带分解（互斥，全部限制在项目既有全帧支持集 `gt_image > 0` 内）

```
D = GTMC 动态
S = ~D 且 GT 深度有效        （= exp36 的静态带）
I = ~D 且 GT 深度无效        （13-14% 的像素，此前从未被单独量过）
```

主配置 combined（mask-ON, prune, color-refined `final_after_opt`），seed0，interval 5。

| | **balloon**（输 RGD 3.58 dB） | **mv_no_box**（追平 RGD） |
|---|---:|---:|
| 全帧 PSNR | 21.81 | 24.70 |
| **D 动态** | 20.96 dB · 7.2% px · **20.0% err** | 24.73 dB · 2.8% px · 4.8% err |
| **S 静态深度有效** | 24.12 dB · 79.4% px · 54.5% err | 26.63 dB · 84.0% px · 58.4% err |
| **I 深度无效** | 20.49 dB · 13.4% px · **25.5% err** | 21.32 dB · 13.2% px · **36.8% err** |
| **动态可达域** | **+1.43 dB** | **+0.33 dB** |

**忠实性锚**：本探针 balloon seed0 全帧 = 21.81 dB，主表 3-seed 均值 = 21.56 dB
⇒ 同一 regime，装置可信。

## 3. 判读

### 3.1 方向判死（主判据）

完美重建动态内容（D 带误差归零）最多买到 **+1.43 / +0.33 dB**。
即使 balloon 上全部兑现，21.81 → 23.24，距 RGD 的 25.14 仍差 1.9 dB。
⇒ **"重建动态内容关闭渲染差距"不成立**；该方向若要存在，必须换主张，不能挂渲染差距。

### 3.2 "动态内容是个洞"这个前提本身不成立

D 带在 balloon 上是 20.96 dB、在 mv_no_box 上是 **24.73 dB（与静态带 26.63 只差 1.9 dB）**。
color refinement（26000 iter 纯光度精修，见 `p3_terminal_mech_autopsy.md`）**已经把动态区
拟合到接近静态区的水平**——它对全部训练视角做光度拟合，动态像素也在其中。
⇒ 一个"动态重建分支"要打败的不是空洞，而是一个已经拟合到 21–25 dB 的烘焙结果，
头部空间只有 ~3 dB × 7% 面积。这与 exp36 的老结论同源：
**该指标很大程度在量"地图对自己那套训练视角的解释程度"。**

### 3.3 输在哪：静态带，不是动态带（跨序列对照给出的）

balloon 的静态带 24.12 vs mv_no_box 的 26.63 = **差 2.5 dB**，
而我们在 mv_no_box 上追平 RGD、在 balloon 上输 3.58 dB。
⇒ **balloon 的渲染劣势主要坐落在静态带**（mask 大面积介入的那条序列上，
静态重建本身更差），不是"动态内容缺失"。

### 3.4 新信息：深度无效带（本项目从未量过）

**13–14% 的像素承担 25.5%（balloon）/ 36.8%（mv_no_box）的渲染误差**，
逐像素误差密度是静态带的 2.0–2.8 倍。这些像素没有任何深度监督（Bonn RGB-D 传感器无回波：
镜面、远墙、物体边界），只靠光度外插。
⇒ 这是一个真实的、结构性的、与动态无关的误差来源。**记录在案，但它不是动态 SLAM 的贡献**
（最高准则第 3 条：头条必须动态相关）。

## 4. 花费与自限

- **零 GPU campaign**：两次离线重渲（88 + 156 帧，2060，各数分钟），无新 SLAM run。
- 单 seed、两序列、仅 balloon/mv_no_box 有冻结 GTMC mask（f3_wk_xyz 为 0 张，该口径不可得）。
- 只判"动态重建的渲染可达域"，**不判**该分支对 ATE / 新视角合成 / 感知质量的价值；
  PSNR 之外的指标（LPIPS/SSIM）未纳入，动态区的**视觉**质量与 PSNR 可能不同序
  （exp36 已测到 PSNR 与 SSIM/DepthL1 在同一支持集上give 相反次序）。
- 本轮**不撤回**任何既有判决；exp36 的渲染侧结论全部保持。
