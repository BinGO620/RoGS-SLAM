## 2. 三处更正我自己上一轮的话

1. **「配对化大概也过不了、大概率 UNREACHABLE」—— 错了。**
   我在等批时按 A/C 臂的地板外推，预计 `floor_paired ≈ 0.10 > 0.0831`。
   实测 **0.0662**，配对**确实**买到了分辨率。外推错在：A/C 臂的 `|ΔP|` max 0.0831 是
   **单个复跑对**的值，而本轮的统计量是**三个 seed 的均值**，均值把单对的离散摊薄了。
2. **「F 比 E 更散，因为放大①剔除更多像素 ⇒ 约束更少 ⇒ 对初始化更敏感」—— 不成立。**
   实测 within-config `|ΔP|` 均值 **E 0.0662 vs F 0.0634** —— F 并不更散。
   真实情况是**两臂的 seed2 都不稳**（0.1296 / 0.1520），是 seed 而非臂的性质。
   该解释上一轮已标为"候选、未测"，现在测了，**判否**。
3. **「exp36/exp37-hard 那两个 G1 门插入门真响了也会报 OK」—— 错了**（见 §4）。

## 3. 一个新的描述性读数：放大通道①**使这个终点变差**

`shift = +0.0806` 是**正的** —— 把硬 mask 从前 10 次迭代扩到全部 100 次，
动态帧上的逐帧跟踪惩罚**升高**。门跑前明确**不预言方向**，所以这是读数不是打脸。

方向与 **P1b 测到的杠杆效应同向**：剔除像素 ⇒ 信息矩阵 `H` 变小 ⇒ 放大 nuisance 驱动的偏差
（P1b 实测 `corr(剔除比例, oracle−all) = +0.21/+0.31`）。
⇒ 可诚实说的是：**在这个终点上，tracking 侧的硬 mask 不只是无用，扩大作用域还略有害。**

**⚠ 必须同时写的三条界**：
1. **margin 只有 1.22×**（方差匹配口径 1.72×）。按注册规则过了，但不宽裕；
2. **门证明的是"P 会动"，不是"效应逐 seed 一致"**。配对位移 −0.005/+0.161/+0.086
   本身很散（符号 2/3，**符号不是判据** —— 预注册 §0），地板只刻画 run-to-run 噪声、
   不含处理效应的 seed 间变动；
3. 地板是 **6 个 within-config 差**上的 max over 8 个符号向量 —— 薄估计，且被 seed2 主导。

## 4. 顺带修掉一个装置缺陷（并更正我对它的第一次描述）

收批时 `violations=6`，全是**假警报**。根因是全家 runner 都写了

```bash
hits=$(grep -c "pat" "$log" 2>/dev/null || echo 0)
```

`grep -c` 在**零匹配**时既打印 `0` 又以状态 **1** 退出 ⇒ `|| echo 0` 也执行 ⇒ 值成 `"0\n0"`
⇒ 后续整数比较**报错而不是比较**。

**实测出的确切后果（不是推理）**：只有零匹配会被污染（非零匹配 `grep` 退出 0，值干净）：

| 写法 | 零匹配 | 非零匹配 | 后果 |
|---|---|---|---|
| `if [ "$hits" -gt 0 ]; then BAD; else OK; fi`（exp36 trackside、exp37 hard） | 报错→假→**OK**，而真实计数确实是 0 | 值干净→正确标 VIOLATION | **碰巧答对，没有漏放违规** |
| `[ "$hits" -eq 0 ] && OK \|\| BAD`（exp37 配对 runner） | 报错→假→**BAD** | 正确 | **6 个假警报**（本轮） |

**⇒ 我第一次把它描述成「插入门真响了也会报 OK 的静默门」是错的**，已在三个 runner 的注释里更正。

**实质读数用直接测量独立复核，无一改变**：
- 本批 6 run 真实插入门计数 **全 0**（日志各 28KB 非空）；
- exp36 trackside 6 run 真实 **全 0**（G1 6/6 结论成立）；
- 正控制：`eboth_balloon_seed0` = **67 次**、`pba_mapping_off_balloon_seed1` = **67 次**
  ⇒ 「处理臂 0 / 对照臂 67」这个模式是直接量出来的。

已改为 `|| true` + 整数守卫（坏值报 `MALFORMED` 并计入不过），
并由 `tests/test_runner_log_gates.py`（4 条）钉住 —— **门要对已知坏输入测，不能只对已知好输入测。**
