# Step C 设计稿 —— 把方差-偏置诊断下沉成逐像素在线估计

> **状态 = 设计稿，非预注册。** Phase 1 判决出来之后才定稿并单独预注册
> （Phase 1 的三分支结果直接决定本稿怎么写，见 §5）。
> 上游：`exp39_phase0_verdict.md`（MECHANISM-LIVE）、`consult_codex_exp39_direction.md`（§5.4）。

## 1. 为什么需要它（不是"因为想加东西"）

Phase 0 证明了连续加权触达优化器，但**它不是方法内核**。codex 的判定我方采纳：

> `w = huber(residual) × dynamic_prior` 的诚实名字是"鲁棒残差权重 × 动态先验"。
> Huber 只反映**当前残差幅值**，不区分「高方差噪声」与「低方差但有系统偏差」；
> `1−s` / 语义 mask 是**动态性先验**，不是**已发生的相干偏置**。
> 这个乘积**不是**方差-偏置分解的实现，只是把 tracking 侧的老形态搬到 mapping。

而本项目 exp37/38 真正测到的东西恰恰是那个分解：

| 终点 | shift | margin | 方向 |
|---|---:|---:|---|
| P（逐帧动态惩罚） | +0.0806 | 1.22× | 变差（**方差**项） |
| coherent_amp（相干幅度） | −0.0248 | 1.38× | 降低（**偏置**项） |
| ATE | −1.4157 | 4.0× | 变好 |

**关键不对称**：噪声沿轨迹平均掉，偏置累积。⇒ 观测的价值不由残差大小决定，
而由**残差的相干性**决定。**这是我们自己测出来的，且当前没有任何在线机制在用它。**

⇒ Step C = 把这个分解从「整条轨迹的事后测量」下沉为「逐像素的在线估计」，
并让 BA 的观测聚合按它加权。

## 2. 机制

对每个关键帧的每个像素维护两个低成本状态（mapping 循环里同一批关键帧每次迭代都会被重渲，
所以时序样本是免费的）：

```
μ_t = β·μ_{t-1} + (1-β)·sg(e_{t-1})        # 有符号残差 EMA（RGB 三通道向量 / depth 标量）
q_t = β·q_{t-1} + (1-β)·sg(e²_{t-1})
b̂² = ‖μ_t‖²                                 # 相干（偏置）分量
σ̂² = max(q_t − ‖μ_t‖², σ_min²)              # 波动（方差）分量
w   = clip( [h(r_t)/(σ̂² + λ·b̂² + ε)] / EMA(mean·), w_min, w_max )
```

**三条防自激的硬要求**（codex 提出，我方采纳）：
1. 状态只在 `no_grad` 内更新；
2. 用**上一轮**残差（滞后一步），不用当前轮，否则权重与梯度即时互相放大；
3. 权重按滑动均值归一化后再 clip —— 且**归一化方式必须与 Phase 1 的尺度匹配设计一致**，
   不能在治疗臂里偷偷改变 loss 尺度而没有对照。

**与 Phase 0 的关系**：Phase 0 的 `floor` 是**常数权重**；Step C 是**逐像素自适应权重**。
Phase 0 的装置（`mapping_weight.py` 的注入点、探针、尺度匹配对照臂）**可原样复用**。

## 3. 判别实验（本稿最重要的部分）

一个"新内核"最容易的失败方式不是无效，而是**换皮**——表面上是新公式，
实际行为与 `huber × prior` 无异。所以预注册必须包含**三条能把换皮抓出来的读数**：

| # | 读数 | 换皮会怎样 | 真内核会怎样 |
|---|---|---|---|
| **D-1** | 新权重与旧权重（`huber×prior`）的逐像素相关性 | 高相关（>0.9） | 明显低于 1，且差异集中在"高残差但不相干"的像素 |
| **D-2** | 静态区域中**持续同号残差**的响应 | 无特异响应（旧形态看不见符号） | 该类像素被降权（这是旧形态**不可能**做到的） |
| **D-3** ⭐ | **把 EMA 状态在像素间打乱 / 每轮重置** | 行为不变（说明时序状态没起作用） | 权重分布仍在但**效果消失** |

**D-3 是承重条**：它把"效果来自时序信息"变成可证伪的断言，而不是从公式形式推断。

## 4. 已知失效模式（预注册须逐条列出，不得事后补）

1. 地图未收敛 / 曝光漂移 / 系统性渲染误差被误判为动态偏置（**这是最可能的一条**：
   欠重建的静态区域也有持续同号残差）；
2. 往返运动使有符号均值相消（钟摆型 mover 的 b̂² 被低估）；
3. pose/map 突变后状态滞后 ⇒ 持续错误降权；
4. 低方差区权重爆炸，或 clip 大面积饱和（退化成常数权重 = 回到 Phase 0）；
5. 被降权像素不再改善 ⇒ 自我维持的错误反馈。

> 第 1 条与第 5 条合起来是本设计的**主要风险**：它们会让机制"看起来在工作"
> （权重分布漂亮）而实际在惩罚欠重建。**D-2 必须同时报静态区域的假降权率**，
> 否则读数会把这条风险读成成功。

## 5. 与 Phase 1 结果的耦合（为什么现在不定稿）

| Phase 1 判决 | 对 Step C 的含义 |
|---|---|
| **SHAPE-MATERIAL**（W 优于 S） | 权重形状本身有价值 ⇒ Step C 是"把常数形状换成自适应形状"，动机最强 |
| **SCALE-EXPLAINED**（W 优于 H 但不优于 S） | 常数软化的收益只是尺度 ⇒ Step C **更重要**：它主张的是**逐像素判别**，恰恰是常数 floor 给不了的东西。但预注册必须先说清"我们已经知道常数形状无效" |
| **SOFT-WORSE** | 放回动态梯度有害 ⇒ Step C 的方向要反过来：不是"放回有用观测"，而是"更准地剔除相干观测"（同一套 b̂ 估计，用法相反） |
| **INDISTINGUISHABLE** | mapping 侧对权重形状整体不敏感 ⇒ **Step C 降级**，应先回答"为什么 29% 的梯度变化换不来 ATE 变化" |

**四种结果里没有一种会让 Step C 变得没意义，但它们要求的预注册叙述完全不同**
—— 这就是不提前定稿的理由。

## 6. 成本估计

- 装置：EMA 状态 = 每关键帧 2 个 (1,H,W) 缓冲（float32 ≈ 1.2 MB/KF，window 12 ⇒ ~30 MB），可接受；
- Phase 0（机制自检）：2 run，复用现有探针 + 新增 D-1/D-3 读数；
- Phase 1（信号量级）：balloon + mv_no_box × 三臂（新内核 / Phase 0 的常数 floor / 硬 mask）= 6 run。
