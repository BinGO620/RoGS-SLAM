## 1. H-DEMARC（我主张两条死判决不覆盖"在线 mapping 侧连续加权"）

**codex 立场（置信度 0.88）**：作为"该代码路径尚未被直接测试"的**范围声明成立**；
作为"因此旧 NO-GO 不适用"的**安全结论不成立**。

**它的反打（我方采纳）**：mapping loss 优化的是 `L(G,{T_k}) = Σ w·ρ(r(G,T_k))`，
**同时更新高斯参数 G 与窗口关键帧位姿 T_k**（joint BA）。改 `w` 改的不只是观测数量，
而是**梯度、Hessian 与极小值位置**。动态像素只要 `w>0` 就仍在推高斯与位姿 ⇒
死判决 A 的失效模式可能以 **map–pose 共适应**的形式复现。

> **我方裁决 = 采纳。** 写进预注册风险节，并据此把"BA 可观测性"列为 Phase 0 必测诊断量
> （见 §3）。同时保留我方的边界：DBA-lite 是离线 post-hoc + 几何 point-to-plane，
> 参数化/初始化/时间耦合都不同 ⇒ **不可把 9/9 单调变坏直接外推为 mapping 必败**（codex 同意这点）。

## 3. 臂设计：A2（语义软化）先进 Phase 0 —— codex 同意（置信度 0.84）

## 4. ⚠ 新增：尺度混淆（codex 发现，代码已核实，置信度 0.96）

**事实**（`utils/slam_utils.py:626-652` + `slam_backend.py:438-439`）：
`l1_rgb.mean()` 的分母是**全图 H×W，与 mask 无关**；而 `loss_mapping += 10 * isotropic_loss.mean()`
是**固定尺度**。⇒ 改 floor 不只改权重形状，**同时改光度项幅值及其对正则项的比例**。
"只换聚合方式"的单变量声称**不严格成立**。

三选项中 codex 选 **(iii) 加尺度匹配对照臂**（(i) 会重定义已冻结硬臂语义、破坏历史可比；
(ii) 让 Phase 1 任何结果都无法区分"权重形状收益"与"光度项相对正则项变弱"）：

```
L_hard-scale = c · L_hard ,  c = Σw / (Σm + ε) ,  c 必须 detach()
```
RGB 与 depth 的有效像素集不同 ⇒ **分别**算 `c_rgb` / `c_depth`。

**三分支读法（跑前钉死）**：
- soft 优于 hard，但**不**优于 scale-matched hard ⇒ 收益来自 loss 尺度，**权重形状主张塌**；
- soft 仍优于 scale-matched hard ⇒ 才支持"连续权重形状"本身有价值；
- 都无差异 ⇒ 软化无可测机制收益。

> **我方裁决 = 采纳。** Phase 1 从 2 臂变 3 臂（+2 run）。这是本轮**成本上唯一的净增**，
> 但它买的是归因能力——没有它，Phase 1 出正数也不能用。

## 5. 方法内核：`huber × dynamic_prior` **不是**内核（置信度 0.90）

codex 判定：Huber/IRLS 权重只反映**当前残差幅值**，不区分"高方差噪声"与"低方差但有系统偏差"；
`1−s` / 语义 mask 是**动态性先验**，不是**已发生的相干 bias**。
⇒ 该乘积的诚实表述是"鲁棒残差权重 × 动态先验"，**不是方差-偏置分解的实现**；
若只是把 tracking 老形态搬到 mapping，**方法内核被明显削弱**。

**它选定的唯一首实装 b̂ 代理 = 逐像素滞后残差 EMA**（因果、低成本、可在 mapping 循环里累积，
因为同一批关键帧每次迭代都会被重渲）：

```
μ_t = β·μ_{t-1} + (1-β)·sg(e_{t-1})          # 有符号残差 EMA（RGB 三通道向量 / depth 标量）
q_t = β·q_{t-1} + (1-β)·sg(e²_{t-1})
b̂² = ‖μ_t‖² ,  σ̂² = max(q_t − ‖μ_t‖², σ_min²)
w_raw = h(r_t) / (σ̂² + λ·b̂² + ε)             # h = 现有 Huber 权重
w = clip( w_raw / (EMA(mean w_raw)+ε), w_min, w_max )
```
关键：**只在 `no_grad` 内更新状态、用上一轮残差（滞后）**，避免权重与当前梯度即时自激。

**最小判别实验（证明它不是老形态换皮）——这条我方认为是本轮最有价值的产出**：
1. 与旧权重的逐像素相关性（高相关 ⇒ 换皮）；
2. 静态区域是否出现"持续同号残差 ⇒ 降权"的响应（老形态不可能有）；
3. **把 EMA 状态在像素间打乱 / 每轮重置**：若权重分布仍在但 mapping 效果消失
   ⇒ 效果真来自时序信息；若无差异 ⇒ 换皮实锤。

**失效模式（预注册须列）**：地图未收敛/曝光漂移/系统性渲染误差被误判为动态 bias；
物体往返运动使有符号均值相消；pose·map 突变后状态滞后导致持续错误降权；
低方差区权重爆炸或 clip 大面积饱和；降权像素不再改善形成自我维持的错误反馈。

> **我方裁决 = 部分采纳（方向采纳，排期不采纳）。** 这条**改变了叙事重心**：
> A2 软化只是**通道验证与对照**，**不是可写进论文的方法内核**；内核候选 =
> 把 exp37/38 的方差-偏置诊断从"整条轨迹的事后测量"**下沉为逐像素在线估计**。
> 但它**不进 Phase 0**（违反分阶预算：机制通道未验证前不实装带状态的估计器）。

## 6. 本轮对项目的净影响（写进 02-method 的部分）

1. **exp39 方向合法**，但合法性来自"新落点 + 我方通道拆分实测"，**不是**来自"旧判决无关"；
   死判决 A 的失效机制（加权改变 joint BA 极小值位置）**必须被 Phase 0 的诊断量看得见**。
2. **死判决 B 的强版本作废**（我方实测反证，codex 撤回）——这条可复用：
   **"同一信号换消费者 ⇒ 无新信息"在本系统中已被证否**，以后不得再用它否决落点。
3. **Phase 1 必须三臂**（soft / hard / scale-matched hard），否则不可归因。
4. **Phase 0 判据升级**：applied_frac 单独**不可**作为判据，须加梯度归因（pose 块 vs 高斯块 ×
   动静分解）、ESS、pose Hessian 最小奇异值/条件数（检测"降权把 BA 变不可观测"）、
   map 污染代理、时间稳定性。
5. **论文内核不在 A2**。若最终只拿到 A2 的结果，按最高准则**不足以当头条**。
