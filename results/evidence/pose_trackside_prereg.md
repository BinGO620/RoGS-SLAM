## 1. 这是一个**新问题**，不是 exp36 那个问题的高分辨率版

exp36 在 balloon 上判 INDETERMINATE：门比的是「ATE 均值差 vs 臂内极差」，E 极差 1.54 吃掉了
两点预言的间距 2.72。**加 seed 救不了**（极差随 n 只增不减，exp35 判据 #12）。按 exp33 判据 #10，
换 estimand ⇒ 新问题 ⇒ 必须重新注册。

**换的是什么**：从「整条轨迹的累积漂移」（ATE）换成「**动态特异的逐帧跟踪惩罚**」。
理由是机制对口 —— E 相对 D 只多两条通道：

- ① tracking 光度损失的硬 mask（只活在 `tracking_itr < warmup_iters=10`，共 100 次迭代）；
- ④ T2 的 MAD 候选集（exp36 实测在分母里只值 0.11–0.18 cm）。

① **作用在逐帧的位姿解算里**。ATE 量的是它累积之后的产物；RPE 直接量它本身。

**两者已被校准证明是解耦的，不是同一个量的两种精度**（这条必须写在前面，防止把本轮结论
读成 exp36 那个问题的答案）：

| 证据 | 读数 |
|---|---|
| null 复跑 `C_mapoff` balloon seed1 | ATE 差 **0.82 cm（10%）**，而逐帧 RPE 中位差 **+0.0078**（在地板上） |
| f3_wk_xyz 的总效应 | ATE **2.82→26.77（~10×）**，但逐帧 RPE 中位差只 +0.026…+0.040 = 地板的 **2.7×** |
| balloon 的总效应 | ATE **3.06→11.96（~4×）**，逐帧 RPE 中位差 +0.100…+0.124 = 地板的 **8.6×** |

⇒ ATE 效应大小与 RPE 效应大小**跨序列不单调**。所以：
**本轮无论判成什么，都不得写成「trackside 解释/不解释那 2.3 cm ATE」。** 它回答的是
「trackside 通道有没有降低动态特异的逐帧跟踪惩罚」。

## 2. 为什么用 RPE，以及为什么它不继承 P1/P1b/P1c 的死法

P1c 给全项目留了一条硬约束：**Bonn 上任何逐帧位姿研究，只要拿 GT 当靶，就有 ~10–19 mm 的地板**
（光度最优点离 mocap GT 那么远），而我们要分的 ATE 差总共 2–3 cm。

RPE 绕开它，且是结构性绕开、不是调阈值：

1. **RPE 是 GT 的相邻帧之差**。那 10–19 mm 是逐帧的**慢变偏置**，在相邻差里大部分相消。
2. **RPE 对全局刚体变换不变** ⇒ 不需要 ATE 那个 Horn 对齐，臂间不通过对齐耦合。
3. 每个 run 给 ~N 个样本而不是 1 个。

口径**复用项目自己的**，不新发明：`evo` 的 `RPE(PoseRelation.translation_part)`，delta=1，
构造方式逐行照抄 `utils/eval_utils.py::_evaluate_trajectories`。
`plot/trj_full_final.json` 存的正是喂给该函数的那两个列表 ⇒ 可逐字节复现出厂数字（见 G-A）。

## 3. PRIMARY estimand：within-run 动态惩罚 P

```
P(run) = median RPE(高动态 pair) − median RPE(低动态 pair)          单位 cm
```

**为什么是 within-run 的差，而不是臂间配对中位差**：臂间配对差里混着两样东西 ——
「E 的地图整体好一点」和「E 在动态帧上专门更好」。P 是**同一个 run 内部**的对比，
臂级全局偏移（地图质量、总体漂移）被差掉，留下的是**动态特异**的那部分 ——
也就是一条动态 mask 通道唯一可能负责的部分。

**协变量**：held-out 冻结 GTMC 掩码的逐帧动态面积占比（`dynamic_mask_gtmc/`，方法从未见过，
manifest spot-check PASS）。对帧走项目自己的 `t3_semalpha_verdict.stem_index`（depth stem 键），
**不是排序位次** —— balloon 是 438 张掩码对 439 帧（GTMC 要 ±2 邻帧），位次 i ≠ 帧 i。
pair i（帧 i, i+1）的协变量 = 两端的 **max**（任一端被污染，相对位姿就被污染）。
覆盖率实测 **438/438 = 100%**。

**分层 = 运动匹配（PRIMARY），plain 作 sensitivity**：高动态帧同时也是相机更快的帧
（balloon `corr(area, GT step) = +0.210`，步长中位数 lo/hi = 0.496/0.654，快 32%）。
运动匹配 = 先按 GT 步长四分位分箱，**箱内**再按动态面积中位数切，然后合并
⇒ 实测 lo/hi 步长 0.590/0.575（配平）。

> 这条对照不是装饰：在 pt1 上 plain 的间距 +0.1925 到运动匹配后**塌到 +0.0716**
> （pt1 的速度混淆是 lo/hi 0.574/0.886 = 快 54%）。**若把 plain 注册成主判据并把 pt1 纳入判决，
> 就会把一个相机速度混淆读成效应。**

## 5. 点预言（跑前写下，可被打脸）

balloon，运动匹配口径：

| 假设 | 预言 P(E) ≈ | 依据 |
|---|---:|---|
| **H-inert**：tracking 侧买不到动态特异的改善 | **+0.3911** | = P(D maskfree) |
| **H-material**：tracking 侧买到了 | **+0.1510** | = maskON 组均值（A/B） |

间距 **0.2401**，地板 **0.0831** ⇒ **2.9×**。

**可达域（exp32 判据 #4，先算再注册）**：本装置能与 0 区分开的最小份额 =
0.0831 / 0.2401 = **35%**。⇒ **份额低于 ~35% 的 trackside 贡献，本装置读不出来，
判 PARTIAL 时必须同时写出这条界。**

## 6. 判决规则（`d_on = |mean P(E) − 0.1510|`，`d_off = |mean P(E) − 0.3911|`）

**第 0 步，停跑规则先响（exp36 逐字继承）**：
若 `range(P(E)) > 0.1200`（= 0.5 × 间距）⇒ **INDETERMINATE**，不读标签、不改判据、不加 seed。

否则：

- **TRACKSIDE-MATERIAL**：`d_on ≤ 0.0831` **且** `d_off ≥ 0.1662` **且** 逐 seed `P(E) < P(D)` **3/3**
  ⇒ P(E) 落 [0.0679, 0.2249]
- **TRACKSIDE-INERT**：`d_off ≤ 0.0831` **且** `d_on ≥ 0.1662` ⇒ P(E) 落 [0.3172, 0.4742]
- **PARTIAL**：两者都 > 地板 ⇒ 报份额 `s = (P(D) − P(E)) / (P(D) − P(maskON))`，
  **并同时写出 §5 的 35% 可达界**（s 只有 ≥35% 才与 0 可分，≤65% 才与 1 可分）
- **ANOMALY（先反打自己，exp32 判据 #6）**：若 `P(E) < 0.0669 − 0.0831 = −0.0162`
  （比全 mask 的最好 run 还好一个地板）⇒ **不贴标签**，当装置疑点处理并写下来

`plain` 口径的同一组读数作为 **sensitivity 并列报出**，不用来翻转判决
（plain 的间距 0.2037 / 地板 0.0727 / 停跑阈值 0.1019；两点预言 0.6236 与 0.4199）。

## 7. 适用域与诚实边界（写在读数之前）

1. **本 estimand 只在 balloon 上可判。**
   - `f3_wk_xyz`：**0 张 GTMC 掩码** ⇒ 协变量不存在 ⇒ 惩罚 P **无定义**。
     讽刺但必须写：exp36 里 ATE 分辨率**最高**的那条判别序列，在这个 estimand 下**完全不可用**。
   - `pt1`：有 580 张掩码，但（a）运动匹配后间距只剩 **+0.0716**，(b) **无复跑 ⇒ 地板不可测**，
     (c) plain 口径下 min-gap **−0.0407**（不完全分离，C 臂强双稳态 0.484–0.751）
     ⇒ **不进判决**，只作为「装置在第二条序列上同向但不可判」的记录。
   - ⇒ **判决是序列局部的。** exp36 刚测出「残差成分逐序列不同」（判据 #15），
     本轮结论**不得跨序列外推**。
2. **P 是联合属性，不是纯 tracking 属性。** MonoGS 是 frame-to-model 跟踪，RPE(t) 依赖 t 时刻的
   地图状态；地图又依赖位姿。所以 P 量的是「该臂在自己建的地图上的逐帧跟踪质量」。
   支撑（不是证明）它在本对比里主要不是地图差异：exp36 静态带测得 C/E/D 的静态带 PSNR
   两位小数**全同 20.39**，且三臂共享 `mask_mapping=false`。**这是约束，不是地图同一性的证明。**
3. **地板只有 4 个样本**（balloon 的 4 对复跑），用 **max** 而非 mean 作地板，已是保守选择；
   但 4 个样本的 max 本身是个粗估计，这条写下来。
4. **协变量的已知偏性**（P1 记过）：GTMC 只标"运动可观测"的像素 ⇒ 天然偏向**有纹理**的像素。
   它对五臂完全相同，故不影响臂间对比；但"动态面积"读作"动态难度"时要带上这条。
5. **`--fast` 的 run 没有 `band_metrics.json`** —— 与渲染侧不同，本轮的锚 G-A **拿到了**
   （出厂 ATE/RPE 就在 `tracking_raw.csv` 里），所以这条限制不适用于本轮。

## 8. 本轮不做什么

- 不加 seed（§1 已论证救不了，且本 estimand 的地板来自复跑而非 seed）；
- 不改 exp36 的任何既有判决（trackside 的 ATE 判决仍是 INDETERMINATE，本轮不翻它）；
- 不为 f3_wk_xyz 现建 GTMC 掩码：`scripts/build_static_eval_mask.py` 的参数集自述
  "仅在 3 条 Bonn 序列上验证过" 且硬编 `CALIB_BONN` ⇒ 移植到 TUM 需要它自己的验证与门，
  拿未验证的协变量去判决正是 P1「强门配弱问题」的同族错误。列为后续可选工作。
