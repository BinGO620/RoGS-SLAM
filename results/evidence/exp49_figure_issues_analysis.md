### 问题2: Fig1 红色背景文字 "optional person mask..."

**问题**: Fig1 图片中有一句红色背景的话：optional person mask....

**诊断**:
- 查看 PDF 提取文本，找到这句话：
  ```
  optional person mask — combined configuration only
  ```
- 查看 `make_fig1_pipeline.py:59-61`:
  ```python
  ax.text(5.6, 4.9, "optional person mask — combined configuration only",
          ha="center", va="bottom", fontsize=5.8, color="#E68A4D",
          style="italic")
  ```

**结论**: 
- 这是 Python 脚本生成的文字，颜色是 `#E68A4D`（橙色，非红色）
- 用户说的"红色背景"可能是指这句话太显眼或排版问题
- **这是设计意图**：用橙色虚线 + 橙色斜体文字标记"可选组件"

**可能的问题**:
1. 字号太小（5.8）但位置突出，显得不协调
2. 颜色太亮（橙色 #E68A4D vs 背景白色）
3. 没有背景框，文字直接浮在图上

**修复选项**:
- A: 删除这句话（信息已在 caption 中说明）
- B: 改为更柔和的颜色（如灰色）+ 稍大字号（6.5）
- C: 移到图例位置，而非横跨整个 pipeline

### 问题4: f3_st_hf 数据异常

**问题**: 表格里 f3_st_hf 效果差了好几个数量级 `35.59±0.47` vs `29.43±8.00`

**诊断**:
```bash
# 查找 f3_st_hf 的实际 run 结果
$ find results -name "*f3_st_hf*" -type d
./runs/P11/P11-REMEDIAL-3090/f3_st_hf_seed2
./runs/P11/P11-REMEDIAL-3090/f3_st_hf_seed0
./runs/P11/P11-REMEDIAL-3090/f3_st_hf_seed1
```

**观察**:
- `35.59±0.47`（std 很小，0.47）→ 稳定
- `29.43±8.00`（std 很大，8.00 = 27% CV）→ 高方差

**这个数据的含义**:
1. **不是"差了几个数量级"**（数量级 = 10×/100×），这里是 35.59 vs 29.43 = 1.21×
2. **真正的问题是高 std**：8.00 的标准差意味着 3 个 seed 之间差异巨大
3. 可能的原因：
   - f3_st_hf 序列本身难度高（high-frequency 运动）
   - Baseline 双稳态（类似 exp43 的 crowd2: 44cm → 97cm 跳变）
   - 某个 seed 崩溃了（如 seed0: 25cm, seed1: 26cm, seed2: 37cm → mean 29.43, std 6.81）

**是否需要重跑**:
- **先检查现有数据**：读取 3 个 seed 的实际 ATE 值
- 如果某个 seed 明显崩溃（>50cm）→ 重跑那个 seed
- 如果 3 个 seed 都在合理范围（20-40cm）→ 这就是真实方差，不重跑
