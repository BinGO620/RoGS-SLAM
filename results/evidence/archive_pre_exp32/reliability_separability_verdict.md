# ReliabilitySignal 机制验证：s 到底分不分得开动/静像素（gap ② 关闭）

> 2026-08-15（exp22）。脚本 `scripts/probe_reliability_separability.py`，本地 2060，零批量消耗。
> 原始数据 `results/evidence/reliability_separability.json`。

## 为什么必须做

论文的机制主张——`s=(1-e_flow)(1-v·g)` 在 Gaussian 准入层降权动态像素——此前只有两条支撑：
(a) ATE 结果，(b) 5 面板机制图。而**机制图的 s 面板是 flow-only 近似**（几何项未存档），
偏偏 P7 说 geometry 是 3/4 序列的最优线索 ⇒ **头条机制图省掉了自己认定最重要的线索**，
这是审稿人一眼能看到的缝。本探针直接测这件事。

## 怎么测

- 用**在线那段代码本身**重建 s：`utils.reliability_signal.compute_reliability_tracking_weight`，
  三种融合模式 both / flow-only / geometry-only 各算一遍，含同一个 Cauchy 权重 `w`。
- 逐像素动态证据 `1-s` 对**冻结的 GT-pose 运动一致性掩码** `dynamic_mask_gtmc/` 打分
  （方法独立、方法从未见过）。报 AUC、分离比 mean(1−s|动)/mean(1−s|静)、以及 `w` 的抑制比。
- 臂 = mask-free MRCS（WP-A K1R1L1），4 序列覆盖三种 regime + 一个失败边界；stride 5。
- **诚实近似（写作必须同写）**：`render_depth`/`opacity` 来自该 run 的**终态地图**（final PLY）
  在其**自身估计位姿**下的重渲，不是帧 t 当时的在线地图。公式与 `f_obs`/`obs_depth` 都是在线的，
  地图不是。这会**高估**几何项（终态图比当时收敛得好），但比它替换掉的 flow-only 图诚实得多。

## 四条结论（都要进论文，包括不利的）

### 1. 信号是真的，但远不是检测器级别（AUC 0.58–0.75）

s 在**所有 4 个序列上都携带真实的动态信息**（AUC 全部 >0.5，balloon 达 0.75），
但**没有一个序列接近分割级别的可分性**。这**不是坏消息，而是与设计自洽**：
MRCS 用的是**软降权 + 鲁棒聚合**，不是硬掩码——一个 AUC 0.6 的先验用作软权重是合理的，
用作硬掩码会灾难。**它同时解释了为什么加回真 mask（combined）在困难序列上仍有大幅提升**：
我们的先验捕捉到部分动态证据，但捕捉不全。

### 2. 固定 `both` 从来不是最优融合——**像素层独立复现了 P7 的 ATE 层结论**

AUC 上 flow-only ≥ both 出现在 3/4 序列，geo-only 只在 pt2 胜出；**没有一个序列 both 最优**。
乘法融合把强线索**稀释**了。P7（48 run，ATE 层）与本探针（像素层）是**两个独立测量层
得出同一结论**："固定双线索乘法不是普适内核"。这比任何单层证据都硬。

### 3. ⚠ 但像素级可分性**不能预测**哪个线索 ATE 更好

P7 的 ATE 排序是 geometry-only 在 balloon/mv_no_box2/pt2 最优；本探针的 AUC 排序却是
flow-only 在 3/4 最优。**两个排序不一致。**

⇒ **"检测得更准 ⇒ SLAM 更好"这条直觉在我们的系统里不成立**。合理解释：ATE 由被降权的残差
在**位姿优化**中的作用决定，而不由逐像素判别率决定；一个分离度稍低但**空间分布更有利**
（例如集中在高梯度边缘）的线索可以带来更好的位姿。
**写作后果**：(a) 不得用本表去论证"所以应该选 flow-only"；(b) 这条**加强**了 WP-HS 的负结果——
连"用可分性挑线索"都不成立，难怪序列级语义占比挑不出来；(c) future work 的 selector
必须直接以**位姿误差**为目标，而不是以线索可分性为代理。

### 4. pt1 的失败**不是**因为信号更弱（一个诱人假说被证否）

我原以为 pt1（mask-free 失败，32.41 cm）会显示出比 pt2（成功，9.30 cm）更差的可分性。
**实测相反**：pt1 的 AUC（0.656）不低于 pt2（0.627–0.656），w 抑制比甚至更强（1.70 vs 1.44）。
⇒ **pt1 的边界不能归因于"可靠性信号在那里失灵"**，既有解释（帧间漂移 RPE 2.89 cm/frame
淹没时域一致性）仍然是唯一有证据的解释。这条**防止我们编一个更好听但错误的机制故事**。
