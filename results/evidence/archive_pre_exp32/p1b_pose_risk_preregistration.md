## 0. 为什么这是**新问题**，不是"P1 判据不过就换个门"

外审（codex，93%）给了五项可操作的区分标准。逐项对照：

| 项 | P1（已判 FAIL） | **P1b（本文）** | 是不是换门？ |
|---|---|---|---|
| **干预** | GT-MC 硬剔除（画面 1.1–5.8%） | **MRCS 自己的软权重 `w`** + oracle + 匹配对照 + **纯鲁棒估计基线** | 换算子 |
| **目标量** | `ρ = λ_min` 保留比 | **单步高斯-牛顿位姿更新的偏差 ‖δ‖ 与方差**（mm / mrad） | **换 estimand** |
| **对照** | 同掩码随机平移 | 同掩码随机平移（面积/形状匹配）**＋ 无独立运动的静态序列** | 加控制 |
| **数据** | 7 序列 2357 帧 | 同序列（**不在 P1 数据上做确认性推断**：P1 的 FAIL 不因本实验改变，本实验也不引用 P1 的 `ρ` 作为证据） | 声明隔离 |
| **声明** | "动态区是否特异地更伤 λ_min" | "**剔除动态像素是否降低位姿更新偏差，代价是多少方差**" | 新的操作性假设 |

**P1 的 FAIL 永久保留。** 本实验若 PASS，也**不**能读成"P1 其实成功了"。

**为什么必须换 estimand（外审第 1 条，本轮最重要的一条）**：
`H = Σ w·JᵀJ` 把每个像素当作**符合静态残差模型**的测量。动态像素可以有很大曲率，
同时提供**系统性错误**的梯度方向 ⇒ **大 `λ_min` ≠ 有用信息**。P1 测到的是"**名义杠杆集中**"。
高杠杆 + 有偏残差恰恰是**最该剔除**的一类像素。所以正确的问题不是"该不该保留"，
而是"**剔除之后，位姿更新的偏差与方差各变成什么样**"。

## 1. 被测对象

后向帧对 `(t → t−1)`（与冻结的 `flow_raft/` 同一约定），**在 GT 相对位姿 `ξ*` 处**：

```
r_c(x)  = I^{t−1}_c( π(T_{t−1←t} p(x)) ) − I^t_c(x)          c = R,G,B
J(x)    = ∂u/∂ξ  = flow_jacobian_se3(depth_t, K, R*, t*)      (2×6)
A_c(x)  = ∇I^{t−1}_c(warped)ᵀ J(x)                            (1×6)
g(w)    = Σ_x w(x) Σ_c A_c(x)ᵀ r_c(x)          H(w) = Σ_x w(x) Σ_c A_c(x)ᵀA_c(x)
δ(w)    = − H(w)^{-1} g(w)                     ← 该策略注入的位姿误差，单位 m / rad
Cov(δ)  = σ̂² H^{-1} (Σ_x w² Σ_c A_cᵀA_c) H^{-1}    σ̂² = 加权残差的鲁棒尺度²
```

**在真位姿处，一个完美的策略给出 `δ = 0`。** 所以 `‖δ‖` 就是**偏差**，单位是毫米与毫弧度 ——
不经过 ATE、不经过任何 run、不受 ≥6% 噪声地板与双稳态影响。

**三条明写的近似**：(1) 只用 RGB 项（MonoGS 深度项权重 0.05；加它需要正确处理 `Z` 变换，
本实验为控制实现风险不做，明写为局限）；(2) 用**帧对**直接对齐代替 MonoGS 的"渲染图 vs 观测图"，
偏差机制（动态像素拖动位姿）相同，但不是同一个目标函数；(3) 单步 GN，不是完整迭代。

## 2. 五条臂

| 臂 | `w(x)` | 问的问题 |
|---|---|---|
| `all` | ≡1 | 不做任何事，动态像素注入多少偏差 |
| `robust` | Cauchy IRLS（4 迭代，尺度 = 残差自身 MAD），**不知道任何动态信息** | **纯鲁棒估计的基线** —— 我们必须打败它 |
| `oracle` | `1 − GT-MC` 硬剔除 | 理想动态剔除的上界 |
| `shift` | `1 − (GT-MC 随机平移)`，面积/形状匹配 | **失效控制**：剔除同样多的像素但位置随机 |
| `mrcs` | MRCS 免分割可靠性（**flow-only 变体**，离线可算：冻结 RAFT + GT 位姿 + 深度 → `e_flow` → `tau=median+1.4826·MAD` → `w=1/(1+(d/tau)²)`） | **我们的算子做到了多少** |

`mrcs` 是 flow-only（几何线索 `g` 与 opacity `v` 需要在线地图，离线不可得）⇒
**只能读作"MRCS 的 mask-free 单线索臂"**，不是完整 MRCS。明写。

序列：P1 的 7 条 + **`rgbd_bonn_static_close_far`（无独立运动的负控制）**。
后者无 `flow_raft/` ⇒ 只跑 `all/robust/oracle/shift` 四臂。

## 3. 判决规则（先于数据）

逐序列取各臂 `‖δ_trans‖`（mm）的**中位数**。定义偏差下降率
`red(arm) = 1 − med‖δ(arm)‖ / med‖δ(all)‖`。

**第 0 关 —— 装置门（先于一切主判据；不过则不出任何判决）**：
1. `red(oracle) ≥ 0.30` 于 **≥4/7** 动态序列 —— 否则装置看不见动态偏差，主判据不可读；
2. `red(shift) ≤ 0.10` 于 **≥5/7** —— 否则"剔除任何一块都降偏差"，比较失去意义；
3. 负控制 `static_close_far` 上 `red(oracle) ≤ 0.15` —— 否则下降与"独立运动"无关。

**主判据（PRIMARY）**：`mrcs` 拿到 oracle 降幅的一半以上 ——
`red(mrcs) ≥ 0.50 · red(oracle)` 于 **≥4/7** 动态序列 ⇒ **PASS**。
`red(mrcs) ≤ 0.20 · red(oracle)` 于 **≥5/7** ⇒ **FAIL**。其余 = INDETERMINATE。

**次判据（SECONDARY，报告但不 gating）**：
- `med‖δ(mrcs)‖ < med‖δ(robust)‖` 的序列数 —— **打不过纯鲁棒基线，方法就没有差异化**；
- 方差代价：各臂 `sd_trans`（mm）相对 `all` 的膨胀倍数；
- 综合风险 `sqrt(bias² + var)` 的臂间排序。

## 4. 判据可达域自检（**这次条件化在实际规模上**，P1 的教训）

- 所有门都是**比值**，不含绝对尺度 ⇒ 只要 `med‖δ(all)‖` 不为零就可达；
  而"不为零"由**第 0 关第 1 条**先行验证（`red(oracle) ≥ 0.30` 隐含 `med‖δ(all)‖ > 0`）。
- `red ∈ (−∞, 1]`；`0.30` 与 `0.50·red(oracle)` 都落在可达区间内部。
- **主判据与装置门不冲突**：装置门只约束 `oracle` 与 `shift`，主判据只约束 `mrcs`，
  三者可同时满足（不存在 T2 那种算术互斥）。
- 若 `med‖δ(all)‖ < 0.05 mm`（低于双线性插值噪声量级）⇒ **不出判决**，报"无可测偏差"。

## 5. 无论结果如何的产出

- **PASS** ⇒ 我们第一次拿到 MRCS 的**逐帧机制证据**（"它把位姿更新偏差降了多少"），
  而且完全不经过 ATE ⇒ 绕开 ≥6% 噪声地板。这是主表 4–14× 增益一直缺的因果链。
- **FAIL** ⇒ MRCS 的 mask-free 单线索臂在**单步位姿偏差**上做不到 oracle 的一半，
  那 4–14× 的增益就**不在这条机制上**，必须另找（且这是零 GPU 得到的结论）。
- 两种情况都产出一张 `‖δ‖` 逐帧表，和一个**从未量过的数**：动态像素在 Bonn 上
  每帧注入多少毫米级位姿偏差。

### 7.1 增加一条**次级分析**（描述性，不 gating）：δ 的"漂移分量 vs 抖动分量"

单帧 `‖δ‖` 把两种性质完全不同的误差混在一起：

- **抖动**：曝光变化、遮挡边界、深度边缘、双线性插值 —— 逐帧近似零均值，**会相互抵消**，对 ATE 伤害有限；
- **漂移**：动态物体在一个事件内朝**同一方向**持续拖拽位姿 —— **时间相干**，累积成轨迹误差。

ATE 主要由后者决定。所以除 §3 的中位 `‖δ‖` 外，另报（**不作判据**）：

```
coherent(arm, W) = ‖ mean_{i∈window W} δ_i ‖ / mean_{i∈W} ‖δ_i‖      W = 10 帧
```

`coherent → 1` 表示该窗口内的位姿误差同向累积（漂移）；`→ 0` 表示互相抵消（抖动）。
逐臂比较 `coherent` 与 `‖Σ δ‖`（窗口内累积位移），并按 GT-MC 掩码面积分层。

### 7.2 若装置门不过，怎么读

§3 第 0 关若不过（`oracle` 降不动偏差），**按预注册不出主判决**。但那本身是一个结论，
必须写成：**"在 GT 位姿处的单步帧间直接对齐里，位姿更新偏差不由动态像素主导"**，
并同时报告 `robust` 臂 —— 若 `robust ≈ mrcs`，则我们方法在这个终点上的收益**只是鲁棒性、
不是动态感知**，那是对头条叙事的一记实打实的反打，必须照记。
