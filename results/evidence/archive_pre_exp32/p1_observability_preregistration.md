## 0. 为什么做这个（与 M2 判负的关系）

M2 用"锚点像素数"**代理**位姿可观测性，判负 0/3。判负证明的是**"别用代理量"**，
不是"可观测性方向无关"。本实验换成**直接量**：加权高斯-牛顿信息矩阵
`H = Σ_x w(x)·J(x)ᵀ J(x)`（6×6，MonoGS 位姿只有 6 参）。

但**本实验不做崩溃预警**（那个叙事家族在 f3_st_hf 上已被 M2 连同参照量一起判死）。
本实验问的是一个**前提性**问题，而且是关于**我们自己的方法**的：

> **动态 SLAM 的通用做法是"把动态像素剔除/下权重"。这个动作会不会特异地
> 削弱剩余像素对位姿的约束——超过"随便挖掉一块同样大小同样形状的区域"？**

- **是** ⇒ "鲁棒剔除"与"位姿可观测"存在真实张力。解决这个张力 = 一个
  **动态相关 / 框架通用 / 免分割 / 内核是我们自己的** 方法核（外审提示的
  "自有内核应放在'不确定性如何进入 BA'"正是这个位置）。且它天然接到 MRCS 已有的
  **覆盖采样**分量上（把"均匀覆盖"换成"信息均衡覆盖"）。
- **否** ⇒ 张力在数据层就不存在，**不要建**。代价 0 GPU-h。

**本实验不产生任何 ATE 读数，也不需要任何新 run**：全部量在数据层（GT 位姿 + 观测 RGB-D +
冻结的 held-out 掩码）上算，因此与双稳态噪声、run 间方差、噪声地板 ≥6% 全部无关。

## 1. 被测对象（公式，先于代码）

逐帧 `t`，在 **GT 位姿**处（数据层属性，不依赖任何 run）：

| 量 | 定义 | 来源 |
|---|---|---|
| `J(x)` | `∂u/∂ξ ∈ R^{2×6}`，`ξ=(ν,ω)` 左扰动 | `utils/reliability_signal.flow_jacobian_se3(depth, K, R=I, t=0)`（已在用、有单测） |
| `G(x)` | `Σ_c ∇I_c ∇I_cᵀ ∈ R^{2×2}`，`I∈[0,1]` 三通道 | 观测 RGB（去畸变后，与在线同一像素空间） |
| `j_d(x)` | `a_z − ∇Dᵀ J ∈ R^{1×6}`，`a_z=[0,0,1, Y_c, −X_c, 0]` | 观测深度 |
| `C(x)` | `α·JᵀGJ + (1−α)·j_dᵀj_d`（6×6，对称 PSD） | `α = Training.alpha = 0.95`（MonoGS 追踪损失口径） |
| `H(S)` | `Σ_{x∈S} C(x)` | |

有效像素：`depth>0.01` 且 `J`、`G`、`j_d` 全有限。

**三条明写的近似**（不藏）：
1. MonoGS 追踪损失是 **L1**，其 Newton Hessian 不是 `JᵀJ`。这里测的是**加权像素集合的
   信息几何**（Fisher 型），即"哪些自由度还被约束住"，不是精确 Newton 步长。
2. 用**观测**图像/深度的梯度代替**渲染**图像/深度的梯度（追踪收敛时二者一致，直接法通用做法）。
3. 在线深度项还乘 `opacity>0.95` 掩码；离线不可得，本实验只用 `depth>0.01`。

**参数化声明**：`ν` 单位米、`ω` 单位弧度 —— 与 `cam_trans_delta` / `cam_rot_delta`
优化器实际所见一致，所以 `λ_min` 在这个参数化下是有意义的。
`log det H` **对任何固定线性重参数化只差一个常数**（`det(AᵀHA)=det(A)²det(H)`），
因此臂间 `Δlogdet` 是**参数化不变量**，用作交叉校验。

## 2. 三条臂 + 零假设（先于数据）

| 臂 | 剔除集合 `M` | 含义 |
|---|---|---|
| `gt` | `dynamic_mask_gtmc/` 冻结掩码（held-out，方法从未见过） | 理想动态剔除 |
| `null(k)` | 把**同一张** `gt` 掩码**整体随机平移**得到（k=1..32） | **面积、形状、连通结构完全一致，只随机化位置** |
| `ctrl` | 与 `gt` 面积匹配的**随机平移掩码**（再抽一张，与 null 同分布） | **失效控制**：它对 null 应当无超出 |

零假设的构造刻意选"平移同一张掩码"而不是"随机散点"：散点掩码几乎不改变条件数，
会把判据变成走过场。平移保面积保形状，只问"**动态物体所在的那个位置**是否特殊"。

**计数匹配**：只接受"被剔除的**有效**像素数"落在 `gt` 的 ±15% 以内的平移；
每帧最多试 200 次平移，凑不满 8 个合格 draw 的帧标记 `null_infeasible` 并**排除出主判据**
（排除帧数必须报告）。

**深度匹配零假设（声明为稳健性臂，不参与判决）**：把平移再限制到
"掩码内有效深度中位数落在 `gt` 的 ±25% 内"。若效应在深度匹配下消失，
结论必须写成"**近距离本身就是全部原因**"，而不是"动态区特殊"。

## 3. 逐帧统计量

- `λgt = λ_min(H(all) − H(gt))`（剔除后剩余集合的最弱方向信息）
- `λnull_k = λ_min(H(all) − H(null_k))`
- `ρ = λgt / median_k λnull_k` ← **效应量**（<1 表示真掩码伤得更狠）
- `excess = 1[ λgt < q05_k(λnull_k) ]` ← **频率**（构造上的偶然率 = 0.05）
- 同样口径算 `logdet` 版本：`Δld = logdet(H_kept_gt) − median_k logdet(H_kept_null)`，
  `excess_ld = 1[ Δld < q05_k ]`，效应量 `Δld` 本身（负值 = 真掩码信息损失更大）。

**帧准入**：`gt` 剔除的有效像素数 ≥ 500（否则剔除本身可忽略，`ρ` 会被舍入噪声主导）。
每序列若可用帧 > 400，按均匀间隔下采样到 400（成本控制，规则先于数据）。

## 4. 判决规则（PASS / FAIL / INDETERMINATE）

序列集合（**先于数据固定，7 条，全部拥有 `dynamic_mask_gtmc/`**）：
`balloon, balloon2, moving_nonobstructing_box, moving_nonobstructing_box2,
person_tracking, person_tracking2, moving_obstructing_box`

逐序列算 `frac_excess = mean(excess)`、`med_ρ = median(ρ)`。

- **PASS（前提成立，值得建内核）**：**≥4/7** 序列同时满足
  `frac_excess ≥ 0.20` **且** `med_ρ ≤ 0.67`。
  （频率门 = 4× 偶然率；效应门 = 真掩码只留下平移掩码所留最弱方向信息的 2/3 以下。
  **两个门必须同时过**：只有频率没有效应量，等于"一致地小一点点"，不足以支撑一个方法。）
- **FAIL（前提不成立，方向就地关门）**：**≥5/7** 序列满足 `frac_excess ≤ 0.10`
  **或** **≥5/7** 序列满足 `med_ρ ≥ 0.90`（效应存在但不实质）。
- 其余 = **INDETERMINATE**：如实报告，**不建内核**，并写明是哪一侧不达标。

**失效控制（gating，先于主判据执行）**：`ctrl` 臂的 `frac_excess` 必须 ≤ 0.10 且
`med_ρ ∈ [0.85, 1.18]`。**任一不满足 ⇒ 零假设构造被判为坏掉，本实验不出任何判决**
（不得以"控制臂也超出"为由改读主臂）。

**参数化交叉校验**：若 `λ_min` 口径 PASS 而 `logdet` 口径的 `frac_excess_ld < 0.10`，
整体降级为 INDETERMINATE 并注明"结论对位姿参数化敏感"。

## 5. 判据可达域自检（交接判据 #7）

- `frac_excess` 的可达域是 `[0,1]`，偶然率 0.05；`0.20` 可达（无算术禁区）。
- `ρ` 可达域 `(0,∞)`；`gt` 与 `null` 同面积同形状，`ρ=1` 是"位置无关"的自然值 ⇒
  `0.67` 不是不可达的极端值。
- 两个门**不互斥**：`frac_excess` 高必然伴随 `ρ` 系统性偏低，方向一致，不存在
  T2 那种"两条门在算术上不可能同时满足"的情况。
- `ctrl` 臂与 `null` 同分布 ⇒ 其 `frac_excess` 期望恰为 0.05、`med_ρ` 期望恰为 1.0，
  控制门 `[0.85, 1.18]` 留了有限样本余量（32 draw、400 帧）。

## 6. 无论结果如何，本实验的产出

- **PASS** ⇒ 拿到"剔除-可观测性张力"的**量化**证据 + 它在哪些序列/帧上最严重
  ⇒ 才有资格设计在线机制（届时再单独预注册在线判据）。
- **FAIL** ⇒ 一句可写进论文的诚实结论："在 Bonn 动态序列上，动态区剔除对位姿可观测性的
  影响与同面积同形状的任意区域**无法区分**" ⇒ 该方向关门，0 GPU-h。
- 两种情况都产出一张**可复用的逐帧信息矩阵表**（`H_all`、`λ`、`logdet`、掩码统计），
  后续任何"可观测性"类问题都可直接查表，不必重算。
