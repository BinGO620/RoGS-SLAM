## Q1（置信度 93%）：新问题 vs 换门的**可操作**区分

它给的表（我们已把它写进 P1b 预注册 §0 作为准入条件）：

| 判断项 | **新问题** | **同一问题换门** |
|---|---|---|
| 干预 | 实际语义或软权重算子 | 扩大原 GT 掩码 |
| 目标量 | 部署算子的偏差与方差、失败风险 | 仍是同一个 `ρ` |
| 对照 | 权重分布、面积、拓扑均匹配 | 只重新选阈值 |
| 数据 | 密封留出序列或新数据 | 继续用 P1 数据确认 |
| 声明 | 新的操作性假设 | 宣称补救或确认 P1 |

- **P1 的 FAIL 必须永久保留**；"门写错了"只能作为**后验方法学诊断**。
- 外审会看四件可审计的事：P1 不改主终点 / 探索性结果明确标注 / 新阈值不在原数据上承担确认性推断 / 后续用预先冻结的算子与终点。
- **它纠正了我一处**：`med_ρ≤0.67` **不是不可达**（正对照与 balloon 尾部都够到了）。
  真正的设计错误是**口头问题与决策门不一致**——问题问"是否特异地更伤"，门问"是否在多数帧多损失约 1/3"。**强门配了弱问题。**
- **它明确警告**：语义二值掩码与自研软权重**不是一个算子**，不应放进同一个"可择优"的篮子。

## Q2（置信度 89%）：排序 **(iii) 偏差×可观测性联合局部实验 > (i) 真实算子重做 > (ii) 关门**

- **最大概念漏洞不是阈值，而是 `H` 把动态像素当成符合静态残差模型的信息。**
  动态像素可以提供很大 Hessian，同时提供**系统性错误**的梯度方向。**大 `λ_min` ≠ 有用信息。**
- 真正该比的是**位姿更新风险**：`g=Σ JᵀWr`，`δ̂=−H⁻¹g`；动态像素不只改 `H`，还改 `E[g]` 与 `Cov(g)`。
  更贴近目标的量是 `‖H⁻¹E[g]‖² + tr(H⁻¹Cov(g)H⁻¹)`。
- 下一步应从受控位姿扰动出发比较一次或少数几次 GN 更新，臂 = 不剔除 / oracle 静态 / 实际可靠性权重 /
  **面积及权重分布匹配的随机对照** / 可靠性+可观测性保护。**主终点 = SE(3) 更新误差与失败率，不是 `λ_min`。**
- balloon 的尾部要先把"**帧尾巴**"变成"**事件尾巴**"：连续帧高度相关，25% 可能只是少数长片段。
  应报连续退化时长、窗口化信息矩阵、按动态事件的 block bootstrap。
- **会让它改排序的证据**：实际算子在冻结参数下产生持续方向性退化 / 时间窗口聚合后仍存在 /
  局部位姿更新误差变坏 / 通过分块统计检验 ⇒ 提 (i)。反之纹理匹配后效应消失 / 尾部集中在极少数事件 /
  可观测性保护改善不了位姿更新误差 ⇒ 提 (ii)。

## Q3（置信度 74%）：内核**只有 20–30% 是我们的**

- 退化检测 / `λ_min`、条件数监测 **不新**；用 logdet、`λ_min`、信息增益选特征 **不新**；动态场景剔除不可靠像素 **不新**。
- "当掩码导致退化时保留高信息像素"很容易被评为**两个已知模块的直接组合**，而且**直接保留高杠杆动态像素可能恢复 `H` 却增加位姿偏差**。
- 它认为**可能未被占据**的位置：
  > 一个**不把可疑动态像素重新伪装成静态测量**的、可靠性校准且**偏差感知**的观测管理器。
  联合决定：哪些残差可用于 tracking / 哪些高斯进入 mapping / 可信静态信息不足时是否**收缩可估自由度、
  增强运动先验、延迟更新、请求关键帧或扩展时间窗口** / 如何在动态污染风险与位姿风险之间给出可验证的 Pareto 改善。
- **最低强基线**：reliability-only、observability-only、两者简单相乘、约束式联合策略、oracle static mask。
- 核心证据不是"提高了 `λ_min`"，而是联合策略**同时**降低动态偏差、退化失败与地图污染。
- 它自陈这只是"可能未被充分占据"，**不是已证实的空白**（无系统检索）。

## 它明确不同意我的五条

1. 不同意"门不可达"——是**强门配弱问题**，不是不可达。
2. 不同意直接称"7/7 显著"——帧不独立，缺时间分块不确定性；稳妥说法是"7/7 方向一致且超过帧级 null 基线"。
3. 不同意"深度解释不了"——中位深度 ±25% 只排除了**一个粗粒度**解释。
4. 不同意把纹理选择一概称 artifact——若部署算子确实依赖可测运动，它就是端到端系统的**真实机制**；
   只有在声称"动态语义本身造成信息富集"时才是混杂。
5. **最不同意**：把 `H` 的减少直接解释为有效位姿约束减少。**对模型失配的动态像素，曲率可以很强而信息是有偏的。**
